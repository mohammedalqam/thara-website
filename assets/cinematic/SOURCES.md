# THARA cinematic homepage sources

- `thara-courtyard.glb`: original conceptual architectural model authored for this THARA redesign. Editable source: `src/cinematic/villa-model.js`; rebuild with `npm run build:cinematic`. This is an architectural study and must not be advertised as an available rental property.
- Geometry, furniture, door hinge, glazing, foliage and architectural fixtures are generated from the original source code. No downloaded third-party model is included.
- Entrance plaque uses the unmodified existing `assets/logo.jpeg` at runtime. The original photograph/logo bytes are unchanged. Its ownership/usage follows the existing THARA repository; this work grants no new third-party rights.
- Extruded lettering reuses the repository's existing `src/brand-geometry.js` Roman-serif paths. This is not a newly substituted company emblem or an exact vector reconstruction of the JPEG wordmark. The lack of the original vector logo remains documented.
- Procedural surface bump maps are deterministically generated by `src/cinematic/materials.js`; the study uses the same visual family. These are original authored surfaces, not measured PBR scans.
- `thara-letters.glb`: exported from the existing Roman-serif outlines, with five distinct named mesh nodes. The homepage creates the same geometry from its source and controls each node independently.
- `poster-desktop.webp`, `poster-mobile.webp` and the frames under `docs/cinematic-v4/renders/`: CPU Cycles renders of the actual exported geometry and supplied camera poses, converted to WebP. Generated by the retained Blender scripts. They are posters and architectural review frames, **not WebGL screenshots**. Cycles illumination and micro-texture nodes differ from the realtime renderer. No generated photograph substitutes for the listed properties.
- Three.js 0.180.0 and its GLTFLoader, GLTFExporter, RoundedBoxGeometry, BufferGeometryUtils and RoomEnvironment are MIT licensed. See the root `THIRD_PARTY_NOTICES.txt` and generated bundle legal notice.
- No external asset licenses, paid subscriptions, stock photographs or additional framework are introduced.

Status: native-scroll homepage implemented on the isolated design branch. Actual WebGL inspection and hardware frame-rate measurements remain required before release. The cloud browser currently reports GL_VENDOR/GL_RENDERER Disabled; static browser review and offline rendering cannot close that gate.
